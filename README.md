# Sistema de Gestión Escolar

**SistemaEscuela** es una aplicación de escritorio desarrollada en **C# con Windows Forms**, diseñada para gestionar información de estudiantes en una institución educativa. Utiliza **SQL Server** para almacenar los datos y permite realizar operaciones CRUD de manera simple e intuitiva.

---

## Características

- Registro de estudiantes con información como nombre, apellido, edad, dirección y curso.
- Visualización de los registros en un `DataGridView`.
- Modificación y eliminación de registros existentes.
- Conexión a base de datos SQL Server mediante `SqlConnection`.
- Validaciones básicas de campos y control de errores.

---

## Tecnologías Utilizadas

- C# (.NET Framework)
- Windows Forms
- SQL Server
- ADO.NET
